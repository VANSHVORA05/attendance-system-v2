# Attendance System

A face recognition based attendance system built with Python and Streamlit.

## Features

- Face recognition based attendance
- Student enrollment
- Google Sheets integration
- Webcam support
- Automatic attendance marking

## Tech Stack

- Python
- Streamlit
- OpenCV
- face_recognition
- Google Sheets API
- gspread

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Notes

Google API credentials must be stored securely using Streamlit Secrets (`.streamlit/secrets.toml`). This file is intentionally excluded from the repository.
