# Face Recognition Attendance System

This project is developed to automate the attendance process using face recognition. The system detects a student's face through the webcam, compares it with the stored images, and marks attendance automatically.

# 🎓 AI Face Recognition Attendance System

A modern AI-powered Attendance Management System built with **Python**, **Streamlit**, **OpenCV**, and **face_recognition** for real-time face detection and attendance tracking.

---

## ✨ Features

- 🎥 Real-time face recognition
- 👤 Student face enrollment
- ✅ Automatic attendance marking
- 🖥️ Simple Streamlit interface
- 📁 Local attendance storage
- ⚡ Fast and accurate recognition

## How to Run

1. Install the required packages.
2. Run `streamlit run app.py`.
3. Enroll students.
4. Start face recognition.

- app.py – Main application
- enroll.py – Add new students

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/VANSHVORA05/attendance-system-v2.git
```

Go to project directory

```bash
cd attendance-system-v2
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
